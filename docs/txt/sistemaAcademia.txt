**Sistema de Academia**

Classe: Aluno
Atributos:
- id: int
- nome: String
- cpf: String
- email: String
- telefone: String
- dataNascimento: LocalDate
- ativo: boolean
- dataCadastro: LocalDateTime
Regras (AlunoController): nome obrigatório; CPF com 11 dígitos e único; e-mail válido (se informado); nascimento não futuro.

Classe: Plano
Atributos:
- id: int
- nome: String
- valorMensal: BigDecimal
- descricao: String
Planos iniciais: Mensal, Trimestral e Anual.

Classe: Matricula
Atributos:
- id: int
- alunoId: int
- planoId: int
- extras: String
- descricao: String
- valorTotal: BigDecimal
- dataInicio: LocalDate
Regras (MatriculaController): só aluno ativo se matricula; o pagamento é processado antes de gravar; matrícula e pagamento são gravados na mesma transação.

Classe: Pagamento
Atributos:
- id: int
- matriculaId: int
- metodo: MetodoPagamento (PIX, CARTAO)
- valor: BigDecimal
- codigoTransacao: String
- aprovado: boolean
- dataHora: LocalDateTime
Pagamento simulado (PagamentoController): Pix sempre aprovado; cartão exige 16 dígitos e número terminado em 0000 simula saldo insuficiente.

Extras (padrão Decorator): Personal Trainer, Avaliação Física, Aulas Coletivas e Nutricionista, somados ao valor do plano.

Padrões de projeto aplicados: Singleton (ConnectionFactory), Decorator (PlanoServico e extras) e Observer (MatriculaPublisher).
